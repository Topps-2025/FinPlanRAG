# FinPlanRAG 当前进度与后续实验

## 1. 当前论文定位

本文研究的不是“现有 RAG 不会多轮检索”，而是一个可证伪的任务—表示假设：在金融多跳问题中，显式维护独立证据路径、未闭合义务、限制证据、来源谱系、事实有效时间和公众可得时间，是否能改善下一步检索以及继续、断言或拒答决策。

当前允许的主张是：

> filing/period-aware 义务表示缺口已经在真实美国与中国金融任务中出现，但当前尚未证明 FinPlan 的动作策略相对同元数据强基线具有独立优势。

这里的“尚未在该任务和表示下验证”不是“现有 Agentic RAG 原理上做不到”。若 Generic 或 HiREC-style 方法获得相同金融元数据后追平，论文必须删除策略优越性主张。

## 2. 已完成的 research-gap 证据

### 2.1 SEC 点时关系轨道

- 15 条真实 SEC 交易 lineage 的历史回放已复现 future leakage；移除 `available_at` 后，探索/留出样本泄漏率为 58.8%/41.7%。
- 原始 FinPlan v1 曾弱于通用自适应与 HiREC-style 诊断；加入路径绑定后在小样本上改善，但不足以证明 SOTA。
- 该轨道说明公众可得时间、路径串线和限制证据是实际问题，不只是合成设定。

### 2.3 中国 FinGLM 公开轨道

- 已核验 FinGLM 11,588 份2019—2021年年报清单与复赛A 2,000题/答案；FinGLM2 有101组、311个子问题，但数据库和金标答案未公开，不能冒充完整 RAG benchmark。
- 9道跨年题、18份巨潮官方年报和3,567页语料已完成冻结 pilot。
- 冻结5题中，原始 entity-only FinPlan 闭包0/5；entity-year 扩展后为5/5，但 metadata decomposition、Generic 与 HiREC-style 也均为5/5。
- Single-shot 闭包5/5，但错误文档率为0.4667，说明其高召回依赖额外噪声。
- qid 357 和1493分别存在姓名简繁字形、英文大小写伪差异；原始标签和规范化语义标签已分开保存，不归因于 RAG。
- **FinGLM 全集基线已一次性运行并冻结**（2026-08-12 协议 `finglm_protocol_v1.json` 预注册后运行，2026-08-13 run4 落盘）：语料 11,588 份年报（2019×3450 / 2020×3870 / 2021×4268，1 份 002861_2020 源码损坏排除 → corpus 11,587 文档）；1829 题（2000 − 171 排除，排除理由入档 `finglm_full_cases_v1.json`）× 4 方法 = 7,316 行，BUDGET=4，全部经由与 LOFin 全集中字节一致的 `retrieve_policy`（import 复用）。

  - single_shot：closure 0.7594 / wrong_doc_rate 0.8087 / documents 3.99

  - generic_adaptive_period：0.9885 / 0.2712 / 1.53

## 4. 方法状态和优化空间

原框架已经出现两类需要修正的问题：

1. `entity-only` 或 `entity-year` 义务键会折叠独立年度/期间；
2. period-aware FinPlan 即使修复表示，也没有超过拥有相同元数据的 Generic/HiREC-style 基线。

下一版优先优化规划状态和动作策略，而不是继续调 BM25：

- 义务扩展为“主体/证券代码、文档类型、财政年度、财政期间、指标或关系槽位、cutoff”；
- 增加同公司同年多文档 collision 检测；
- 区分主体识别失败、期间映射失败和证据检索失败；
- 保留独立路径和限制证据动作，并用相同 metadata、语料、模型和预算比较；
- 分开报告义务闭包、文件闭包、页级证据闭包、真实 reader 正确率和停止/拒答质量。

validation7 暴露、validation8 预声明确认的 v9 修改（全部在 manifest 冻结后才运行方法，未在已运行冻结集上改动）：

- "fiscal year N"（以及 H1/H2 之外的自然期间短语）进入 period 解析，修复 fy_q1n 层 0/3——**validation8 确认**：fy_q1n 5/5（v8 0/5）；
- "first n quarters" 改为只取 Qn 所在累积文件，消除 h1_9m 的 Q1 过度检索——**validation8 确认**：h1_9m wrong_doc 0.000 vs v7/v8 0.333；
- 半年度别名映射（H1→Q2、H2→Q3+FY）已在 validation7 冻结集确认，validation8 保持默认表示——**维持确认**。

validation8 同时给出诚实负结果：与 v9 共享义务、仅检索退化为元数据分解 fill_missing 的对照（P4）闭包与 v9 完全持平（24/24），即级联检索策略在本轨道无独立于表示的增益——论文的策略优势主张只落在表示层（期间解析），不落在动作策略。

只有开发集失败可以用于改架构；修改后必须在未观察的公司/公告链冻结集确认。若强基线继续追平，贡献收缩为金融证据义务表示、多场景 benchmark 和可审计协议。

## 5. 金融域通用性的边界

FinPlanRAG 不限于收购，但“通用”只指金融域内共享状态接口。目前规划四类场景：

1. 生命周期关系：并购、控制、许可、供应关系的签署—条件—完成/终止；
2. 会计推导：定义—组件—期间—单位—计算；
3. 点时指标：报告类型、财政期间、data vintage 与截止时点；
4. 比较调查：跨公司/跨年度对齐、共同定义和来源冲突。

至少两条真实、非同源轨道在非 oracle 端到端冻结测试中显示共享状态接口的独立增益后，论文才使用“金融域通用”表述；不声称优于任意领域的通用 agent。

## 8. 当前结论

Research gap 已获得部分真实证据：金融多跳任务确实暴露路径串线、期间义务碰撞和点时泄漏。期间表示层（自然期间措辞 + 别名 + 跨年度边界解析）已在两个独立冻结集上被确认是真实且必要的：validation7 别名层（p≈.03）、validation8 冻结 24 题上 v9 相对 v7-shared baselines 的闭包优势首次显著（p≤0.00024）。但**公共 LOFin 完整 1,572 题全集（2026-08-12 冻结）给出了更强制的校准**：全集上 v9/v8/v7/period_metadata_decomposition 闭包均为 0.892–0.895 且互不显著，v9 vs generic_adaptive_period 打平（p=1.000）——validation8 的表示层优势未能在全集上保持为显著；v9 相对 public baselines 中真正稳健的增益只剩错误文档率（0.31 vs single_shot 0.80 / hirec 0.62）与对 hirec/single_shot/v4 的闭包优势；义务精确匹配仅 0.46，文件级闭包 ≠ 答案准确率。全集同时确认 validation8 的两条负面证据：预声明 P2（fiscal-year 措辞层 v9>v8）被证伪（v8 反而更高），metadata fill 与 v9 完全持平（disc=0），**级联检索策略无独立于表示的增益**。因此”FinPlan 动作策略优于现有改进方法”仍未成立，论文的策略优势主张必须收缩到表示层，且表示层的全集增益主张需按上述口径如实陈述（分层、非全集整体）。**中国 FinGLM 全集（2026-08-13/14 冻结，n=1829）给出跨语言的更强校准**：义务感知基线闭包 0.986–0.991 vs single_shot 0.759（p<1e-100），wrong_doc_rate 0.012/0.271/0.560 全对显著（p<0.0001）——义务表示缺口在第二语言、第二个数据集上成立；**内部方法 v9（所有显式年份义务解析）闭包 0.9978，首次在全集上显著超过全部义务感知外部基线（vs pmd p=4.8e-07、generic p=7.6e-05、hirec p=0.0018），wdr 0.0126 与 pmd 持平（p=0.878）且远低于 generic/hirec**——增益精确落在 2-2 多年比较层（p<1e-6），完全归因于义务表示（metadata_fill 与 v9 逐位相同，本轨道单义务检索无策略自由度，策略层主张依旧不可声称）。后续实验的价值是回答：哪一种动作策略能在公平强基线下真正产生独立增益（目前唯一稳健候选是错误文档率），以及中国机制轨道能否在更广场景复现表示层证据。
