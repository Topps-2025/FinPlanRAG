# 最接近工作逐篇核验

来源等级：A=同行评议正式论文；B=预印本或本轮只核读预印本版本。页码为实际阅读 PDF 页码，不等于论文印刷页码。

## 跨论文比较

| 工作 | 等级 | 已解决 | 与本文仍需检验的差异 |
|---|---:|---|---|
| IRCoT | A | 推理与检索交错，多步问题逐轮取证 | 轨迹主要是自由文本推理，不维护金融关系证据义务和点时状态 |
| FLARE | A | 根据生成置信度决定何时、检索什么 | 信息需要来自待生成句子，不是关系路径闭包 |
| Self-RAG | A | 按需检索、相关性/支持度反思与可控生成 | 反思 token 不等于路径级证据义务和限制证据状态 |
| Adaptive-RAG | A | 按问题复杂度路由无检索、单步与多步策略 | 路由在检索前决定，不根据关系证据状态逐步更新 |
| DRAGIN | A | 根据实时信息需要决定 when/what to retrieve | 状态仍由模型内部不确定性和上下文注意力刻画 |
| EfficientRAG | A | 关系识别、迭代检索与多跳 QA 效率 | 面向通用问答关系，不处理金融权利生命周期、反证和可得时间 |
| TimeR4 | A | 时间约束重写、时间感知检索与重排 | 处理事实时间，不等价于历史认知可得时间与路径级 supersession |
| Sufficient Context | B | 定义上下文充分性并用于选择性生成 | 作者明确未研究检索方法如何形成充分上下文或迭代取证 |
| HiREC / LOFin | A | 金融层级检索、证据过滤、answerability 与补充问题 | 最接近工作；状态是 passage sufficiency，不区分多条权利路径、限制证据义务和点时关系状态 |
| FinSearchComp | B | 真实金融多步搜索、时间敏感数据、多源核验和工具规划 benchmark | 已证明痛点真实，但只做结果级评价，不提供关系状态规划方法或路径级过程标签 |
| Search-R1 | B | 用 RL 学习推理与多轮搜索交错 | 结果奖励不显式约束金融证据义务、限制证据与历史可得时间 |

## 代表性论文卡

### IRCoT（2023）

- 来源：ACL 2023 长文，DOI `10.18653/v1/2023.acl-long.557`，A。
- 作者事实：方法将 chain-of-thought 与检索交错，用当前推理生成下一轮查询，面向知识密集型多步问题。
- 对本文的含义：不能把“多轮检索＋推理交错”作为创新；必须比较 IRCoT 风格自由规划。
- 尚未覆盖的可检验差异：论文任务是给定问题的多步 QA，未展示金融关系模板、路径级证据义务、限制证据和 `available_at` 状态。
- 原文定位：PDF p.1，Abstract/Introduction；PDF p.4–6，Method；PDF p.9，实验分析。

### FLARE（2023）

- 来源：EMNLP 2023，DOI `10.18653/v1/2023.emnlp-main.495`，A。
- 作者事实：FLARE 以待生成句子的低置信 token 触发检索，并以前瞻句子构造查询。
- 实验边界：在 4 个长文本知识密集任务上比较单次和多次检索；检索过多可能引入噪声。
- 对本文的含义：when/what to retrieve 已被明确研究；本文只能研究金融证据状态是否提供不同于 token 不确定性的动作信号。
- 原文定位：PDF p.1，Abstract/Introduction；PDF p.2，Fig. 1 与动机；PDF p.8，Table 2–4 和消融；PDF p.9，Conclusion/Limitations。

### Self-RAG（2024）

- 来源：ICLR 2024，OpenReview `hSyW5go0v8`，A。
- 作者事实：单一 LM 生成检索与批判 reflection tokens，按需检索并评价 passage relevance、generation support 和 utility。
- 对本文的含义：按需检索、证据相关性、支持度和自我批判都不是本文首创。
- 尚未覆盖的可检验差异：reflection token 评价当前生成，不等价于对多个金融关系路径的显式未闭合槽位和点时限制证据建模。
- 原文定位：PDF p.1，Abstract/Introduction；PDF p.3，Related Work distinction；PDF p.4–6，Method；PDF p.10，实验与人工评价。

### Adaptive-RAG（2024）

- 来源：NAACL 2024，DOI `10.18653/v1/2024.naacl-long.389`，A。
- 作者事实：小型分类器按查询复杂度选择无检索、单步检索或多步检索。
- 明示限制：复杂度标签由模型结果和数据集偏置自动产生，可能错标，分类器仍有提升空间。
- 对本文的含义：本文不再声称“自动决定是否多跳”；区别必须是检索过程中随证据状态更新，而非只做查询级预路由。
- 原文定位：PDF p.1，Abstract；PDF p.4，§3；PDF p.9，§6 与 Limitations。

### DRAGIN（2024）

- 来源：ACL 2024 长文，DOI `10.18653/v1/2024.acl-long.702`，A。
- 作者事实：RIND 检测实时信息需要，QFS 使用整体上下文注意力构造检索查询。
- 明示限制：依赖 self-attention 分布与不确定性评分，未来需更强信息需要估计。
- 对本文的含义：通用动态 when/what 已存在；关系约束状态必须与 DRAGIN 在同预算下比较。
- 原文定位：PDF p.1，Abstract；PDF p.3–5，§3；PDF p.9，Conclusion/Limitations。

### EfficientRAG（2024）

- 来源：EMNLP 2024，DOI `10.18653/v1/2024.emnlp-main.199`，A。
- 作者事实：通过 labeler 识别关系与实体，迭代生成查询并检索多跳证据，减少大型 LLM 调用。
- 明示限制：主要在已有多跳 QA 数据上识别关系，开放环境与新关系仍需验证。
- 对本文的含义：关系引导的迭代检索也不是空白；本文差异只能落在金融关系生命周期、限制证据、点时和停止风险。
- 原文定位：PDF p.1，Abstract/Introduction；PDF p.2–3，Method；PDF p.6，Limitations。

### TimeR4（2024）

- 来源：EMNLP 2024，DOI `10.18653/v1/2024.emnlp-main.394`，A。
- 作者事实：以 retrieve-rewrite-retrieve-rerank 显式化时间约束，并同时按语义和时间重排 TKG 事实。
- 明示限制：复杂时间事实检索仍需提高，生成答案格式控制困难。
- 对本文的含义：时间感知检索不是创新。本文必须区分事实发生/有效时间与文档在历史截止时点的可得时间。
- 原文定位：PDF p.1，Abstract；PDF p.5，§4.4–5.1；PDF p.9，Conclusion/Limitations。

### Sufficient Context（2025）

- 来源：实际核读 arXiv:2411.06037 v3，PDF 标注 ICLR 2025；本账本保守按 B 记录。
- 作者事实：定义不预设答案的 sufficient context，发现强模型在上下文不足时仍倾向错误回答，并用充分性信号改善 selective generation。
- 明示限制：未探索不同检索方法产生充分上下文的频率；作者指出可用 autorater 迭代判断继续检索还是回答。
- 对本文的含义：这为“证据闭包驱动停止”提供直接文献基础，也表明该方向是开放问题而非无人想到的问题。
- 原文定位：PDF p.1，Abstract；PDF p.4，§3.1；PDF p.10，Conclusion/Limitations/Future Work。

### HiREC 与 LOFin（2025）

- 来源：Findings of ACL 2025，DOI `10.18653/v1/2025.findings-acl.855`，A。
- 作者事实：对 145,897 份 SEC 文档做层级检索，并用 passage filter、answerability checker 和 complementary question generator 迭代补证；发布 1,595 个 QA。
- 最接近性：它已经覆盖“过滤噪声—判断充分—生成补充问题—继续检索”的金融规划循环。
- 可检验差异：HiREC 的状态是问题级 passage sufficiency；当前材料未显示其维护独立交易/资产路径、关系模板义务、限制证据轨道或历史 `available_at` 截止。
- 原文定位：PDF p.1–2，Abstract/Introduction；PDF p.4–5，Fig. 2 与 §4.2；PDF p.9，Conclusion/Limitations。

### FinSearchComp（2025）

- 来源：arXiv:2509.13160 v1，B；官方页面与 PDF 已核读。
- 作者事实：635 道专家题覆盖实时数据、历史查找和复杂历史调查；70 名金融专家参与构造，结果显示浅搜索、过时证据和多源冲突是现实失败模式。
- 对本文的含义：金融多步搜索与时间痛点是真实的，但不能据此声称关系状态规划有效。
- 任务边界：它是端到端 benchmark，主要评价最终答案，不提供本文所需的路径级证据义务和动作标签。
- 原文定位：PDF p.1–3，Abstract/Introduction；PDF p.5–9，任务与数据；PDF p.14–15，失败分析与 Conclusion；PDF p.29，交叉核验案例。

### Search-R1（2025）

- 来源：实际核读 arXiv:2503.09516 v5，PDF 标注 COLM 2025；保守按 B 记录。
- 作者事实：以结果奖励训练 LLM 在推理过程中多轮调用搜索引擎，不依赖大规模监督轨迹。
- 对本文的含义：可学习搜索策略已存在；FinPlan-RAG 必须与相同模型和检索器下的结果奖励 agent 比较。
- 尚未覆盖的可检验差异：结果奖励未显式惩罚历史信息泄漏、未闭合关系义务或遗漏限制证据。
- 原文定位：PDF p.1，Abstract/Introduction；PDF p.4，Fig. 1 与 RL 目标；PDF p.6–8，搜索 rollout 与实验；PDF p.14，参考边界；附录案例含错误分解和无效重复搜索。
