# Research Gap 与能力矩阵

## 不能成立的旧 gap

以下说法已被文献直接否定：

- “RAG 只会一次检索”：IRCoT、FLARE、Self-RAG、DRAGIN、EfficientRAG 均支持多轮或动态检索；
- “RAG 不会决定何时检索”：FLARE、Self-RAG、Adaptive-RAG 和 DRAGIN 已明确研究；
- “金融 RAG 不会判断缺什么证据”：HiREC 已有 answerability checker 和 complementary question generator；
- “金融 agent 没有多步时点搜索 benchmark”：FinSearchComp 已覆盖。

## 经文献收窄后的真实待验证缺口

> 现有主动与智能体 RAG 已能按不确定性、生成上下文或结果奖励进行多轮检索，金融 HiREC 已能根据问题级证据充分性补充查询；但这些工作尚未在点时金融关系任务中评估一种显式、可审计的关系证据规划状态：该状态同时区分独立关系路径、机制特定证据义务、限制证据、来源谱系、有效时间与可得时间，并将未闭合状态直接用于下一检索动作和继续/断言/拒答决策。

这里的主张是“尚未在该任务和表示下被验证”，不是“现有方法绝对做不到”。

## 痛点真实性与 gap 强度

这不是仅凭直觉制造的金融故事：FinSearchComp 的真实专家题直接观察到浅层搜索、过时证据和多源冲突；HiREC 用 passage filter、answerability checker 与 complementary question generator 说明金融长文档问答确有迭代补证需求；Sufficient Context 发现强模型在证据不足时仍倾向回答，并明确把“检索方法如何迭代形成充分上下文”留作后续问题；TimeR4 则证明时间约束需要专门检索与重排。详细作者事实和 PDF 页码见 [[02-相关工作与Research Gap/01-最接近工作逐篇核验|逐篇核验]]。

因此可作如下分级：

- **真实痛点：有文献和 benchmark 支持。** 多步搜索、证据不足、陈旧信息与冲突确实存在；
- **表示缺口：文献核读下真实但仍是“未展示/未系统评估”。** 尚未发现同时联合路径、义务、限制证据、谱系和双时间的金融规划状态；
- **算法增益：尚未成立。** 受控预实验对公平通用自适应基线没有准确率优势，必须由真实数据和强复现决定。

论文应把前两项分别写成“已观察到的 failure modes”和“待检验的 representation hypothesis”，不能把文献未覆盖直接写成方法有效。

## Gap 的三项可证伪条件

1. **现象门**：在原子证据召回可接受时，真实 agent 仍出现可测的路径混淆、限制证据遗漏或历史可得时间错误；否则删除 gap。
2. **表示门**：给通用 agent 相同关系模板后，显式证据状态仍改善风险、闭包或成本；否则状态表示没有独立贡献。
3. **策略门**：学习型规划超过固定分解和 HiREC 风格补充查询；否则删除算法优越性，保留 benchmark。

## 论文贡献候选

- 一个点时金融关系证据规划任务与过程级 benchmark；
- 一个关系约束的显式证据状态和合法动作接口；
- 一个在相同模板可见条件下学习动作排序与停止的规划器；
- 一套把答案正确率、限制证据召回、未来泄漏、覆盖—风险和成本联合评价的协议。
