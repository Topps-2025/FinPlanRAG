# 基线、指标与公平协议

## 1. 基线阶梯

所有基线按能力递增排列，避免只与朴素 RAG 比较：

1. **No Retrieval**：检验参数记忆与拒答倾向；
2. **Single-shot RAG**：BM25、dense 与 hybrid 各一版；
3. **Fixed Decomposition**：共享关系模板，按固定槽位顺序检索；
4. **IRCoT**：自由文本推理与检索交错；
5. **FLARE / DRAGIN-style**：以生成不确定性或实时信息需要触发检索；
6. **Adaptive-RAG**：无检索/单步/多步路由；
7. **Self-RAG**：按需检索、相关性与支持度反思；
8. **EfficientRAG**：关系引导的多跳迭代检索；
9. **HiREC**：金融层级检索、answerability checker 与 complementary query；
10. **Search-R1 或同等结果奖励搜索 agent**：可学习的通用多轮搜索策略；
11. **TimeR4 / 强时间图检索器**：显式时间约束与重排；
12. **Fixed Relation-State Planner**：与 FinPlan-RAG 完全相同的状态和动作空间，但动作顺序为人工 value-of-information 规则；
13. **Oracle Trajectory**：仅作上界，使用金标下一槽位，不参加显著性排名。

“原论文代码+原模型”可报告复现分数，但主因果比较必须另做统一骨干版本；否则模型规模和检索器差异会掩盖规划贡献。

## 2. 共享条件

主比较统一：

- 同一文档快照、分块、BM25/dense/hybrid 索引和 top-k；
- 同一生成模型、上下文窗、解码参数与最大 token；
- 同一候选路径初始化；schema-aware 基线均可见同一关系模板；
- 同一最大查询数、文档读取数、token、延迟与费用上限；
- 同一时间过滤器和实体解析器；
- 同一 evidence resolver，且所有模型都必须返回原文跨度；
- 不按测试集结果调整 prompt、阈值、来源权重或奖励系数。

另设两个对照：`natural-language-only` 不给结构状态；`same-state-generic-agent` 给通用 agent 同样状态但不做关系动作约束。前者识别状态价值，后者识别关系约束价值。

## 3. 三层指标

### 3.1 最终答案

- Accuracy、macro-F1；有自由文本时补 EM/F1；
- company/time/relation OOD 分层结果；
- 对可回答样本和证据不足样本分别报告。

### 3.2 过程与证据

- 路径识别 Precision/Recall/F1；
- obligation/slot closure Precision、Recall、F1；
- limiting-evidence recall；
- citation entailment 与 evidence-span F1；
- future leakage rate：实际被 resolver/生成器消费的未来文档比例；
- provenance duplication rate：表面多来源但同源转载的比例；
- conflict resolution accuracy；
- 重复动作率、非法动作率与无信息增益动作率。

### 3.3 选择性、安全与成本

- coverage、selective risk 与 AURC；
- 固定覆盖下风险、固定风险下覆盖；
- Brier score、ECE 和可靠性曲线；
- overclaim rate：应拒答或关系未闭包却断言；
- 查询数、读取文档数、输入/输出 token、延迟和货币成本；
- accuracy–risk–cost 三维 Pareto 前沿，不以任意单一 utility 作为主结论。

## 4. 统计协议

- 以 `query_id` 配对比较，bootstrap 置信区间；分类正确性用配对检验并做多重比较校正；
- 至少 3 个随机种子；学习方法报告均值、标准差和最差种子；
- 预注册主指标：`macro-F1`、固定 80% coverage 的 selective risk、limiting-evidence recall、future leakage、平均查询数；
- 同时报告每种关系、路径数、证据稀疏度、冲突密度与 cutoff 距事件时间的分层结果；
- 奖励系数与停止阈值在开发集确定，并报告多组风险偏好的敏感性。

## 5. 公平性判定

若 FinPlan-RAG 只因获得金标路径、更多 metadata、未来时间过滤或更大预算而领先，该结果无效。只有在上述共享条件下，显式状态或学习策略仍改善至少一个预注册风险—闭包—成本指标，且不以另一个关键安全指标显著恶化为代价，才可主张独立贡献。

若通用 agent 加入相同状态后追平，则贡献是状态接口而非金融专用策略；若 fixed planner 追平，则删除学习型算法优越性；若强检索器提升后差异消失，则论文只能讨论检索瓶颈，不能包装为规划创新。
