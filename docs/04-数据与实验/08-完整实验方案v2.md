### 已验证 / 未验证清单

**已获真实证据(可写进论文的 failure modes):**
1. SEC 回放:`–available_at` 导致 41.7%–58.8% future leakage;single-shot 100% 轨迹污染;
2. LOFin 10-K:无路径绑定闭包缺口跨 BM25/BGE/RRF 复现(20/30 vs 30/30);
3. 混合 10-K/10-Q:v6 实体—年份义务碰撞(主体 8/8,义务召回 0,闭包 4/8);
4. 中国 FinGLM:entity-only 闭包 0/5 vs entity-year 5/5;
5. 受控预实验:显式状态减约 1.11 次查询/闭包提高,但准确率与公平通用自适应持平(−0.00018);
6. 中国 mixed-period 页级:期间碰撞下 period-aware 闭包 3/3,entity-only/entity-year 均 0/3(配对 p=0.25,仅方向);与 fixed/metadata/generic/HiREC 追平,不支持策略优势;
7. 答案层:确定性抽取 reader 在冻结 3 题上断言 2/3 全对、缺证据全拒答(entity-only/entity-year 覆盖 0),文件闭包 3/3 与答案层 2/3 的差距由单一页级伪影造成;Qwen2.5-0.5B 自由判定不稳定(三 prompt 变体矛盾),只作诊断。

**未验证(必须补齐才能主张):**

- [x] 真实 reader 首跑(确定性抽取层:冻结 3 题断言 2/3 全对 + 1 诚实拒答;Qwen2.5-0.5B 判定不稳定,降级为诊断层,见 07 §4.3);

## 1. 数据计划

### D1:SEC 生命周期扩展(优先级:中)
- **目标**:15 → ≥30 条 lineage(可行性预检门槛),每条 lineage 构造终局前/终局后两个历史切片;
- **来源**:SEC EDGAR submissions/archives API(已有构建器 `build_sec_real_pilot.py` 可复用);
- **标注单位**:公司组 / 交易 lineage / 时间三重重叠切分;每条至少标注主体解析、交易标识、机制、生命周期、限制证据、双时间、谱系;
- **完成标准**:≥20 例稳定闭包轨迹(30 例中),否则先收窄关系定义。

### D2:LOFin 混合 filing 新冻结集(优先级:高)
- **目标**:构建 validation7——≥15 道多 filing 题(每家公司 ≥2 份同期文件),公司与文件与 validation5/6 零重叠;
- **来源**:SEC API 回溯 10-K/10-Q(构建器 `build_lofin_validation6.py` 复用,增加期间解析);
- **必要性**:当前多 filing 题仅 3 道(validation6),无法检验"多 filing 义务"的策略优势;此集是 v8 的确认性载体;
- **完成标准**:冻结哈希先于方法运行。

### D3:中国 mixed-period 页级(优先级:最高,已完成 ✅ 2026-08-11)
- **现状**:10 份 H1/Q3 PDF + 18 份年报已就位,manifest 已冻结(开发 2 题 + 冻结 3 题);
- **动作**:构建页级语料(H1/Q3/FY 期间键)→ 开发 2 题诊断 → 冻结 3 题一次性运行;
- **义务键**:`security_code × document_type(H1/Q3/FY) × fiscal_year × fiscal_period`;
- **完成标准**:产出 `china_mixed_period_page_pilot_v1.json`(15 文档/1,894 页)+ `china_mixed_period_pilot_v1.json`(冻结结果,data/runner 哈希自记录);
- **结果摘要**:period-aware 闭包 3/3,entity-only/entity-year 均 0/3(p=0.25 方向性);与 fixed/metadata/generic/HiREC 追平,证据页上限 2/3(cnmix-1958 检索面伪影)。

### D4:中国机制链扩展(优先级:中)
- **目标**:问询函—回复、并购进展—完成/终止、处罚—整改、应拒答样本;
- **来源**:巨潮/上交所/深交所公开接口(已有采集器 `collect_china_mixed_period_pilot.py` 模式);
- **每样本字段**:`query_id, security_code, entity, cutoff, valid_time, available_at, document_type, source_url, sha256, obligations, evidence_spans, limiting_spans, answerability`;
- **禁止**:公开原题与自建题混合评分;修订/转载归入同一 provenance family。

### D5:FinRel-PT 正式 benchmark(优先级:中—高,论文核心数据)
- **目标门槛**:≥300 条唯一关系路径、≥100 公司组;若主张跨关系泛化则 ≥3 类关系;
- **关系范围**:收购/控制优先,扩展许可、供应、受监管项目;
- **切分**:company-OOD / time-OOD / relation-OOD;同一交易 lineage 不跨集;
- **标注**:双人独立,分歧第三人裁决;报告路径/槽位/证据跨度一致性;
- **反泄漏**:查询文本不暴露 filing 类型;测试期冻结模板/索引/阈值;
- **阶段 A(检索上限)**:金标主体 + 候选路径下测原子证据 Recall@k;阶段 B(端到端)才测规划。

## 2. 基线阶梯与复现计划

single-shot / fixed decomposition / metadata decomposition / generic adaptive / HiREC-style(透明近似)/ FinPlan v1 / v3 / v4 / v7 —— 共享同一语料、BM25、预算、cutoff。

### 2.2 待复现强基线(优先级:高,决定"策略优势"主张)

| Search-R1 style | 结果奖励 agent:Qwen2.5-0.5B 多轮搜索,相同预算;已有单体自由规划原型(3/30) | 部分原型,未成基线 |

## 3. 三层指标(完整版)

### 3.1 最终答案(真实 reader 层,已首跑)
- Accuracy / macro-F1 / EM-F1;company-OOD / time-OOD / filing-type-OOD 分层;
- 可回答样本与证据不足样本分别报告(coverage–risk);
- **已实现**:确定性抽取 reader(冻结正则 + 规范化相等 + 主体接地,只读方法检索到的页面)在 mixed-period 冻结 3 题上断言 2/3 全对、缺证据全拒答;Qwen2.5-0.5B 自由判定不稳定,降级为诊断层;
- **待实现**:更强 reader 模型(页级证据 → 关系状态标签),必须保留原文跨度引用。

### 3.2 过程与证据(已实现,全部数据)
- 路径识别 P/R/F1;obligation 闭包 P/R/F1;
- limiting-evidence recall;citation entailment;evidence-span F1;
- future leakage rate;provenance duplication rate;conflict resolution accuracy;
- 重复动作率/非法动作率/无信息增益动作率;
- **修复项**:validation6 暴露的"entity 指标从义务反推主体"缺陷——实体识别与期间映射分开审计。

### 3.3 选择性、安全与成本(部分实现,待补)
- coverage / selective risk / AURC;固定覆盖风险、固定风险覆盖;
- Brier / ECE / 可靠性曲线;overclaim rate;
- 查询数 / 文档数 / token / 延迟 / 货币成本;
- accuracy–risk–cost 三维 Pareto,不以单一 utility 为主结论。

### 3.4 统计协议
- 配对 McNemar(已有实现)+ bootstrap CI;Wilson 区间;
- ≥3 随机种子(学习方法);预注册主指标:macro-F1、80% coverage selective risk、limiting recall、leakage、平均查询数;
- 奖励系数/停止阈值在开发集确定,报告多组风险偏好敏感性。
