# 任务定义与研究问题

## 任务输入与输出

输入查询合同：

\[
q=(u,k,t_c,\mathcal{D},\mathcal{T},B),
\]

其中 \(u\) 为公司或主体，\(k\) 为目标关系/概念，\(t_c\) 为认知截止时点，\(\mathcal D\) 为允许语料，\(\mathcal T\) 为关系模板注册表，\(B\) 为检索预算。

系统在第 \(i\) 步维护证据状态：

\[
S_i=(\Pi_i,O_i,C_i,L_i,T_i,P_i,b_i),
\]

分别表示候选关系路径、未闭合义务、冲突、限制证据、时间状态、来源谱系和剩余预算。规划器选择：

\[
a_i\sim\pi_\theta(a\mid q,S_i),
\]

动作包括检索特定槽位、扩展实体或路径、验证时间、检索限制证据、解决冲突、断言和拒答。

## 研究问题

### RQ1：真实失败是否存在？

在共享语料和高原子证据召回条件下，单次 RAG、固定分解、通用动态 RAG 与自由搜索 agent 是否仍出现关系路径混淆、证据义务遗漏、限制证据遗漏和历史可得时间错误？

### RQ2：显式证据状态是否有独立价值？

在所有方法共享关系模板、候选路径、检索器、模型和预算时，显式证据状态是否相对自然语言轨迹或二元 answerability 改善证据闭包、覆盖—风险、限制证据召回或成本？

### RQ3：学习型规划是否优于透明固定规划？

学习型策略是否在公司外推、时间外推和关系外推中超过固定槽位顺序、HiREC 风格补充问题和通用结果奖励 search agent？

### RQ4：停止与拒答是否可校准？

路径闭包、冲突和限制证据状态能否在固定覆盖下降低错误风险，或在固定风险下提高覆盖，并避免以大量额外检索换取表面准确率？

### RQ5：金融域多轨道状态能否迁移？

同一证据状态接口在生命周期关系、会计推导、点时指标和比较调查中，是否能够通过可插拔义务/动作模板保持增益，还是只在收购事件链上有效？

## 可检验假设

- H1：真实困难集中在多路径、限制证据和点时切片，而非普通单跳事实命中。
- H2：显式状态主要改善闭包与成本，不预设必然改善答案准确率。
- H3：关系约束只在与学习型策略共同使用且跨域外推有效时构成算法贡献。
- H4：限制证据提高安全性但会降低覆盖；其价值应由损失函数和 coverage–risk 决定。
- H5：金融任务共享状态接口，但不共享同一闭包规则；跨轨道收益必须由至少两个独立真实数据轨道验证。

## 主任务标签

客观关系状态限定为 `direct / indirect / conditional / none`；`abstain` 是系统动作。底层始终报告路径、义务闭包和时间证据，不以单一标签替代审计轨迹。
