# 术语账本与主张边界

| 规范术语 | 首次定义 | 不得混用 |
|---|---|---|
| FinPlan-RAG | 关系约束的证据状态规划金融 RAG | 不等于通用 Agentic RAG |
| 金融关系证据规划 | 为关系判断选择下一证据动作的序贯任务 | 不等于普通 query decomposition |
| 证据状态 | 当前路径、槽位闭包、冲突、限制证据、时间和预算的结构化状态 | 不等于自然语言 CoT |
| 关系路径 | 同一产品、交易、许可、合同或项目下的证据链 | 不等于公司级全局图 |
| 证据义务 | 某关系模板作出确定结论前必须核验的槽位 | 不等于检索关键词 |
| 限制证据 | 能撤销、缩小或阻止正向关系断言的证据 | 统一使用此词，不再交替使用反证/负证据 |
| 认知截止时点 | 历史判断允许使用信息的最晚可得时刻 | 不等于事件发生时间 |
| 证据闭包 | 必需义务已满足且冲突达到预注册处理条件 | 不等于答案置信度高 |
| 停止动作 | `assert / abstain` | `unknown` 只作拒答输出，不是真实世界类别 |

## 禁止主张

- “首次让金融 RAG 进行多步规划”；
- “现有 Agentic RAG 不会验证证据”；
- “HiREC 没有证据充分性或补充检索”；
- “FinSearchComp 没有时点与多源金融搜索”；
- “受控预实验证明真实金融 gap”；
- “规则模板本身构成 RAG 算法创新”。

## 可检验主张

- 现有方法未在本文任务中评估显式关系路径证据状态；
- 在相同模板可见条件下，证据状态是否改善动作选择、闭包、风险或成本；
- 限制证据与点时过滤是否分别产生安全收益；
- 学习型规划器是否在时间外推、公司外推和关系外推中超过固定分解。
