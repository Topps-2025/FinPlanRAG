# Paper evidence

**Current paper:** the two-branch FinPlanRAG results are in `final/`.  See
`final/README.md` for the artifact map, the reproduction commands, and the
reading notes.  The v2 controlled and decision-layer artifacts below are kept
for provenance; they are not the results reported in the current paper.

The summary artifact was generated from the repository's deterministic
controlled benchmark:

```text
PYTHONPATH=src python -m finplan_rag.controlled_planning \
  --seeds 20 --cases-per-world 40 --budget 10 \
  --out controlled_results.json
```

Source SHA-256 (the local full JSON run):
`E5D207A28136A91CA74B85D0B373C71E5C5D7346AD497E16799B6DB4E42CAA28`.

The benchmark is a controlled mechanism diagnostic. It has synthetic hidden
worlds and should not be read as a financial filing QA benchmark or an SOTA
comparison.

Budget sensitivity is in `budget_sensitivity.json` (budgets 1, 2, 4, 6, 10,
16 with the same seeds and scenarios). It shows the quality-cost frontier and
prevents the main budget from being treated as a universally optimal setting.

`reanalysis_v1.py` reads the frozen per-case artifacts (controlled results,
LOFin full, FinGLM full) and writes `reanalysis_v1.json` with paired bootstrap
intervals (20,000 resamples, seed 20261021) and Wilson intervals for the
24-question holdout. The conference drafts use these intervals; no retrieval or
reader is re-run by the script.

`real_data_summary.json` is a compact audit of read-only legacy FinPlanRAG
results (LOFin, FinGLM, SEC lineages and a Chinese mixed-period pilot). It stores
source paths, SHA-256 hashes and claim boundaries; the large corpora and model
outputs remain outside Git. These values are file-level closure/document
diagnostics unless explicitly labelled otherwise, and are not an answer-accuracy
leaderboard or SOTA claim.

The v2 real-data artifacts are in `company_disjoint_benchmark/`,
`company_disjoint_benchmark_verified/`, `real_benchmark/`, and the four
`real_decision_eval*` directories. They are generated by
`scripts/run_company_disjoint_benchmark.py`, `scripts/run_real_benchmark.py`,
and `scripts/run_real_decision_eval.py`; the claim boundaries are documented in
`paper/v2/company_disjoint_result.md` and `paper/v2/real_decision_result.md`.

The selected non-LLM RF portfolio artifacts are `rf_all_s{1..10}/` (200
trees, ten loss configurations), `portfolio_10seed.json`, and the confirmatory
`portfolio_confirm.json`; both include claim-level bootstrap 95% CIs.
Generated by
`scripts/run_backbone_conformal_diagnostics.py --models rf --rf-trees 200`
and `scripts/analyze_portfolio.py`; the selected algorithm is
`paper/v2/algorithm_selected_portfolio.md`.

### Named baselines, metric suite, rolling benchmark

- `deepseek/named/`, `glm/named/`, and `qwen3/named/`: six named baselines
  (FinDVer, Fin-Fact, Self-RAG, CRAG, FLARE, Adaptive-RAG) on 227 verified
  claims under DeepSeek, GLM 5.3 flash, and locally served Qwen3-8B. The GLM
  run was refreshed on 2026-11-08 with an authenticated key; the previous
  frozen outputs are retained in `glm_frozen_2026-11-07/named/`.
- `*/named/per_claim.jsonl`: parsed label, confidence, credible set, rationale,
  raw response text, token usage, latency, route, and retrieved ids.
- `*/named/prob_*.jsonl` and `*/named/metrics_*.json`: per-claim probabilities
  and the full metric suite for each named baseline;
  `*/named/metrics_summary.json` is the table-ready summary.
- `*/named/model_comparison_logistic.json`: paired McNemar/AUROC comparison
  against the FinPlan logistic evidence model.
- `benchmark_per_claim_verified_calibrated/`: logistic per-claim probabilities.
- `rf_point_per_claim.jsonl`, `rf_point_metrics.json`: RF point artifact used
  as a backbone diagnostic.
- `rolling_benchmark/`: 737-claim rolling-origin RF/logistic artifacts.
- `rolling_remote/`: regenerated 737-claim rolling-origin per-claim
  probabilities and metric-suite JSON under the pinned environment.
- `classical/`: eight classical backbone diagnostics (logistic, histogram
  gradient boosting, random forest, XGBoost, LightGBM, CatBoost, TF-IDF
  logistic, TF-IDF + numeric logistic) on the verified claims.
- `official/{deepseek,glm,qwen3}/`: source-grounded baselines. Each directory
  contains `per_claim.jsonl`, `metrics_*.json`, `model_comparison_logistic.json`,
  `summary.json`, and `provenance.json`; prompt templates are loaded from the
  vendored official repos at pinned commits.
- `final_remote/final_report.{json,md}`: aggregate audit of the benchmark,
  prompt-only and official-source named baselines, decision portfolio,
  sequential experiment, rolling benchmark, router, and controlled diagnostic.

The v3.1 conformal alternative artifacts are:

- `deepseek_conformal_realized_verified/`: DeepSeek, 227 XBRL-verified claims,
  five calibration split seeds; `summary.json`, `per_claim.jsonl`, `report.md`.
- `deepseek_conformal_realized_all/`: the same run on all 273 test claims.
- `conformal_v3_realized_seed{1..5}/`: logistic realized-objective five-seed
  verified runs.
- `conformal_v3_verified_seed{1..5}/`: logistic expected-objective ablation.

Generated by `scripts/run_deepseek_conformal_set_eval.py` and
`scripts/run_conformal_decision_v3.py`; the oracle-fixed regret table is
`regret_summary.json`, generated by `scripts/analyze_conformal_regret.py`. The
algorithm and claim boundaries are in `paper/v2/algorithm_v3_conformal.md`.

### External validity (Tier 1, 2026-11-09)

`external_tier1/` contains the FinDVer and DocFinQA adapters, per-example
outputs, metric summaries, and the cross-backbone report. The runners are
`scripts/run_findver_external.py`, `scripts/run_docfinqa_external.py`,
`scripts/analyze_external_tier1.py`, and `scripts/summarize_external_tier1.py`.
The bounded claim and its counterexamples are documented in
`external_tier1/README.md` and `external_tier1/protocol.json`. Tier 1c (a
second point-in-time task) was not completed.
